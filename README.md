# Skill Hub Releases

Windows desktop installers and automatic update metadata for Skill Hub.

- Download the latest `Skill-Hub-Setup-*.exe` from Releases.
- The application checks this repository for updates, downloads new versions, and installs them when you quit.
- Skill libraries and evaluation records are stored outside the program directory and are preserved across updates.

This repository contains distribution files only. The application source is maintained in a separate private repository.
